Desarrollo Backend

La sala de máquinas: todo lo que ocurre detrás de escena para que el sistema sea seguro, funcional y dinámico.

🖥️

1. El Servidor

Es el computador o entorno (como Apache en XAMPP) que está encendido las 24 horas esperando peticiones del Frontend. Procesa la información usando lenguajes como Java, PHP o Python y devuelve una respuesta.

🗄️

2. Bases de Datos

La bóveda de información permanente. Pueden ser Relacionales (SQL), que usan tablas estrictas, o No Relacionales (NoSQL), que guardan datos en formatos flexibles tipo JSON.

⚙️

3. Lógica de Negocio

Son las reglas matemáticas, condiciones y procesos. Por ejemplo, si compras un boleto, la lógica verifica si hay asientos, descuenta el saldo y te envía un correo de confirmación.

🚪4. Enrutamiento y APIs

Es el mapa de "puertas" del servidor. Define qué código ejecutar según la URL (Endpoint) solicitada. Si el Frontend pide /api/jugadores, el enrutador sabe exactamente a qué base de datos ir a buscar la lista.

🛡️5. Seguridad y Autenticación

El guardia de seguridad. El Backend nunca confía ciegamente en el Frontend. Se encarga de validar contraseñas, generar Tokens, verificar permisos (Autorización) y bloquear ataques cibernéticos.
