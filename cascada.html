Hojas de Estilo en Cascada (CSS)

El lenguaje de diseño que da vida, color y estructura a la web.

¿Por qué se llama "en Cascada"?

CSS funciona con una regla de prioridad. El navegador lee las reglas de diseño de arriba hacia abajo. Si le dices a un título que sea rojo en la línea 10, pero en la línea 50 le dices que sea azul, el azul ganará porque está más abajo en la "cascada" del código.

🌊
⚙️Anatomía de una Regla CSS

Todo el código CSS se basa en una estructura simple: seleccionas un elemento y le aplicas características.

h1 {
  color: blue;
}
🎯Tipos de Selectores
1. Selector de Etiqueta
p { color: red; }
2. Selector de Clase (.)
.boton { background: blue; }
3. Selector de ID (#)
#cabecera { height: 100px; }

El Modelo de Caja (Box Model)

En CSS, absolutamente todo es una caja rectangular. Entender estas cuatro capas es el secreto para dominar el diseño web.

1. MARGIN (Margen Exterior)
2. BORDER (Borde)
3. PADDING (Relleno Interior)
4. CONTENIDO
  • Margin (Margen)

    Espacio transparente hacia afuera. Empuja a otros elementos para que no se peguen.

  • Border (Borde)

    La línea que envuelve la caja. Puede ser gruesa, punteada o de colores.

  • Padding (Relleno)

    Espacio transparente hacia adentro. Evita que el contenido choque con el borde.

🖼️Jugando con los Bordes en CSS

La propiedad border se compone de tres valores principales: grosor, estilo y color. Además, con border-radius podemos suavizar las esquinas.

Borde Sólido border: 4px solid;
Borde Punteado border: 4px dashed;
Borde Redondeado border-radius: 30px;
🎧Muestra de Audio HTML5

Usando la etiqueta <audio> podemos incrustar archivos multimedia directamente en la web. El diseño del reproductor lo define el navegador.
